# 프롬프트 개선기 MVP

## 사용법
1) 이 저장소를 Vercel에 연결 후 배포
2) `/public/index.html` 접속 → 초기 프롬프트 입력 → 질문 1~2개씩 답변
3) 의도/프롬프트 점수 모두 95 이상이면 최종 프롬프트 + MCP JSON 노출
4) "MCP로 전달" 버튼 → /api/mcp 에 POST (데모 echo)

## 암표 신고 도우미 (`/public/report.html`)
판매글 정보를 입력하면 정가 대비 배율을 계산하고 채널별 신고문을 자동으로 작성해주는 도구.

### 입력 방식 3가지
- **① 자동 탐색** — 감시 목록에 공연·정가·기준 배율을 등록하고, 검색 결과를 붙여넣으면
  조건을 넘는 판매글만 골라 후보 큐에 쌓는다. 후보를 고르면 양식과 발견 경위 초안이 채워진다.
- **② 주소·본문 입력** — 세 가지 경로가 있다.
  - **북마클릿(권장)**: 북마크 바에 담아두고 판매글 페이지에서 한 번 누르면 제목·본문·주소가
    그대로 넘어와 자동 분석된다. 사용자의 브라우저가 이미 그린 화면을 읽으므로 로그인이
    필요한 앱이나 자바스크립트로 본문을 그리는 사이트에서도 동작한다. 데이터는 URL 해시로
    전달되고 수신 즉시 해시를 지운다 — 서버로 가지 않는다.
  - **주소 입력**: `/api/fetch-listing`으로 공개 페이지를 읽는다. 다만 주요 중고거래 앱은
    상세 페이지까지 클라이언트 렌더링이라 본문이 비어 온다(번개장터 확인함). 그 경우
    빈 껍데기임을 감지해 붙여넣기로 안내한다.
  - **본문 붙여넣기**: 판매글 본문을 복사해 넣는다.

  추출값은 신뢰도와 함께 표시되고 체크한 항목만 양식에 반영된다.
- **③ 직접 입력** — 모든 항목을 수동으로 채운다.

두 자동 모드 모두 **양식을 채우는 데서 멈춘다.** 사실 확인 체크는 자동으로 풀리고,
신고문 생성·제출은 사용자가 직접 한다.

### 공통 흐름
- 입력 → 자동 분석(웃돈/배율/신고 적합도) → 채널 선택 → 신고문 생성 → 복사 → 기록 저장
- 신고 채널: 플랫폼·예매처 / KOPIS 공연 암표 신고 / 경찰 ECRM / 국민신문고 (채널별 템플릿 상이)
- 기록은 `localStorage`에만 저장. 서버 전송·외부 API 호출 없음. CSV 내보내기 지원
- 가드레일: 필수 항목 검증, 사실 확인 체크 전 생성 차단, 동일 대상 중복 신고 경고, 증거 미첨부 경고, 정가 이하 양도 시 신고 대상 아님 안내
- **자동 제출 기능은 의도적으로 넣지 않았음.** 제출은 사용자가 각 창구에서 직접 한다.

### 파서 (`/public/listing-parser.js`)
판매글 텍스트에서 가격·날짜·좌석·판매자·정황을 뽑는다. 두 자동 모드가 공유한다.

- 금액은 `60만`, `60만5천`, `600,000원`, `600000원` 표기를 인식한다. 날짜(`2026-03-14`)나
  좌석 번호를 금액으로 오인하지 않도록 단위나 천 단위 콤마가 있는 표기만 인정한다.
- 금액 앞 단서(`정가`/`양도가`·`플미`·`장당` 등)로 정가와 요구가를 구분한다. 되돌아보는
  범위를 직전 금액까지로 잘라, 목록형 페이지에서 앞 판매글의 단서가 넘어오지 않게 한다.
- 근거 없는 값은 추측으로 채우지 않고 비워서 내보낸다. 모든 필드에 신뢰도가 붙는다.

### `/api/fetch-listing`
공개 페이지의 `og:title`·`og:description`·본문을 best-effort로 읽는다.

- SSRF 방지: http/https만 허용, 루프백·사설·링크로컬(169.254.x)·CGNAT 대역 차단,
  도메인은 DNS 해석 후 IP 재검사, 리다이렉트는 매 홉마다 재검증(최대 3회)
- 8초 타임아웃, 512KB 상한, 봇 차단 우회는 하지 않음
- 로그인 벽·자바스크립트 껍데기는 감지해서 "본문 붙여넣기" 안내로 넘긴다

## 구조
- /api/_helpers.js       : 공통 JSON 파서(버그 방지)
- /api/config.js         : 기본 설정(슬롯/체크리스트/라우팅)
- /api/score/intent.js   : 의도 점수 계산(슬롯 충족도)
- /api/score/prompt.js   : 프롬프트 점수 계산(체크리스트)
- /api/questions.js      : 부족 슬롯 기반 질문 1~2개
- /api/mcp.js            : 컷오프(95/95) 통과시 중계(echo)
- /public/*              : 정적 UI
- /public/report.*       : 암표 신고 도우미 (독립 페이지)
- /public/listing-parser.js : 판매글 텍스트 추출 파서
- /api/fetch-listing.js  : 공개 판매글 페이지 조회(SSRF 가드 포함)
- /utils/*               : 룰/정규식 기반 엔진
