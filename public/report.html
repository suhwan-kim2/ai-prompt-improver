공연분야 온라인 암표신고센터의 실제 입력 항목에 맞춰 값을 넣어줍니다. 제출 버튼은 누르지 않습니다 — 채워진 내용을 확인하고 형이 직접 접수하세요. 본인인증(휴대전화)과 이메일은 형이 직접 입력해야 합니다.

📝 신고서 채우기 ← 이것도 북마크 바로 드래그 (한 번만)
  1. 위 「신고서 채우기」를 북마크 바에 담아둡니다 (처음 한 번만).
  2. 신고문을 생성한 뒤 아래 「폼 데이터 복사」를 누릅니다.
  3. 공연분야 온라인 암표신고센터 신고서 ↗를 엽니다.
  4. 북마크 바의 「신고서 채우기」를 누릅니다. 클립보드 읽기를 허용하면 항목이 채워집니다.
  5. 내용을 검토하고 증빙파일을 첨부한 뒤 형이 직접 제출합니다.

신고문을 먼저 생성하면 활성화됩니다.

📚 참고: 관련 법령과 포상금

  • 2026년 8월 28일부터 공연법·국민체육진흥법 시행령 개정안이 시행돼, 부정판매자에게 판매금액의 2배~50배 과징금이 차등 부과됩니다.
  • 포상금 — 부정판매를 신고하면 해당 판매자에게 부과된 과징금의 50% 범위에서, 부정구매를 신고하면 최대 5,000만원 이내에서 지급될 수 있습니다. 플랫폼·경찰 신고는 포상금 대상이 아닙니다.
  • 접수 요건 — 신고센터는 좌석번호 또는 예매번호가 특정되지 않으면 유효한 접수로 처리하지 않습니다. 해당 번호가 보이는 링크나 이미지를 반드시 첨부하세요.
  • 공연법 제4조의2 / 제41조 — 매크로 프로그램을 이용한 입장권 부정판매 금지. 위반 시 1년 이하 징역 또는 1천만원 이하 벌금.
  • 경범죄 처벌법 제3조 제2항 제4호 — 공연장·경기장·역 등 현장에서 웃돈을 받고 되파는 행위. 20만원 이하 벌금·구류·과료.
  • 선입금 후 미이행이면 사기로 경찰 신고 대상입니다.
  • 포상금 산정 기준과 지급 절차는 신고센터 공지를 확인하세요. 문의는 공연 1533-1329, 스포츠 02-410-1913. 조문은 국가법령정보센터(law.go.kr)에서 최신본을 확인하세요.
